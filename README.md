# Pixo – Pinterest-Like Image Board

Pixo is a **Pinterest-inspired image board** built using **HTML, CSS, and Vanilla JavaScript**.  
It allows users to **create, view, edit, delete, and search images** in a **masonry (Pinterest-style) layout**, focusing on performance, clean UI, and real-world frontend concepts.

This project is built as a **learning-focused real-world clone**, emphasizing DOM manipulation, state handling, and modern JavaScript patterns without using any frameworks.

---

## Features

### Image CRUD Operations
- **Create**: Add new images with metadata
- **Read**: View all images in a masonry layout
- **Update**: Edit existing images
- **Delete**: Remove images from the board

### Search with Debouncing
- Real-time image search
- Debounced input to improve performance and avoid unnecessary re-renders

### Masonry / Pinterest-Like Layout
- Responsive masonry grid
- Variable image heights
- Optimized layout for different screen sizes

### Sidebar Navigation
- Sidebar with page names
- Settings icon
- Clean, Pinterest-inspired UI

### Header Navigation
- App logo
- Search bar
- Profile avatar
- “Create Image” button

### Hover Effects & UI Interactions
- Image hover overlays
- Action buttons (Edit / Delete)
- Smooth transitions

---

## Concepts & Learnings

This project focuses on **core frontend fundamentals**:

- **DOM Manipulation**
- **Event Delegation** (single click handler for dynamic items)
- **Debouncing** (search input optimization)
- **State Management (Vanilla JS)**
- **Masonry Layout Techniques**
- **Performance Optimization**
- **Clean UI Architecture**
- **Separation of Concerns (UI vs Logic)**
